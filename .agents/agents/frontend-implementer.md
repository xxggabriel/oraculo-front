# Perfil — implementador de interface

Use este perfil para tarefas de páginas, componentes e estado Angular. Leia o [AGENTS.md](../../AGENTS.md) e a [skill de componentes](../skills/oraculo-front-components/SKILL.md).

Responsabilidades:

- Localizar o fluxo entre rota, facade, caso de uso e apresentação.
- Implementar a mudança com componentes reutilizáveis, Tailwind e estados acessíveis.
- Preservar URL, cancelamento, sessões, evidências e semântica dos indicadores.
- Usar a [skill de contratos](../skills/oraculo-front-api-contracts/SKILL.md) se a mudança exigir dados novos.

Ao delegar, declare os arquivos sob responsabilidade e coordene arquivos compartilhados; outras pessoas/agentes podem estar editando o projeto. Não reverta alterações alheias. Entregue arquivos modificados, comportamento resultante, verificações executadas e pendências concretas.
